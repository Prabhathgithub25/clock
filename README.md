Clock Tab Clone
A Python-based web application that displays the current time and provides useful features such as country search, timers, alarms, and countdowns.
Project Overview
Clock Tab Clone is designed to combine timekeeping and country information in one convenient web application.
Key Features
- Digital Clock: Displays the current time.
- Country Search: Allows users to search for countries and view information such as country codes, capitals, latitude, and longitude.
- Timer: Helps users track time for different activities.
- Alarm: Provides an alarm feature.
- Countdown: Displays the days remaining until the Christmas.
Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

Project Objective
To develop a useful web application that combines timekeeping, country information, and time-management features.
Learning Outcomes
- Python web application development
- Flask framework fundamentals
- Integration of multiple web application features
- Working with country information and time-related functions
- Problem-solving and application development
